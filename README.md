# Yohoho x ブロスタ ゲームプロトタイプ — 整理した版（分けたソース）

2026-11-18 の整理後の最新版。`index.html` は骨組みだけで、見た目と動きは全部別ファイルに分かれています。

## ファイル構成（11ファイル＋このREADME）
- `index.html` — 骨組みだけ（HTML）
- `css/base.css` — 土台（色・フォント・共通部品）
- `css/lobby.css` — 待ち受けロビー
- `css/rooms.css` — キャラ部屋／作戦部屋／仲間部屋
- `css/gacha.css` — ガチャ部屋
- `css/game.css` — バトル画面・結果画面
- `js/data.js` — キャラ性能・ガチャ排出プール（ここだけ触れば性能が変わる）
- `js/lobby.js` — ロビー・部屋切り替え
- `js/gacha.js` — ガチャ（コイン・スキン・着せ替え）
- `js/game.js` — バトル本体
- `js/input.js` — PC・スマホの操作

## 遊び方
1. 解凍して `index.html` をブラウザで開くだけで遊べます。サーバーやインストールは不要です。
2. PC：WASDで移動、スペースキーで攻撃（オートエイム）。長押しでため攻撃。
   スマホ：左スティックで移動、右の攻撃ボタンで攻撃（オートエイム）。長押しでため攻撃。
3. プレイヤー＋BOT9人の合計10人バトロワ。最後の1人が優勝（クリア）です。
4. しばらく攻撃も被弾もしなければ、最大HPの6%/秒で自動回復します。

## どこを変えれば何が変わるか
- キャラのHP・速さ・攻撃力・リロード → `js/data.js` だけ
- 見た目・色 → 対応する `css/*.css`
- ガチャの確率・スキン → `js/data.js` の GACHA_POOL

## ガチャの保存について
ガチャのコイン・所持スキン・着せ替えはブラウザ（localStorage）に保存されます。ページを閉じて開き直しても残ります。保存に失敗するブラウザでは、そのページを開いている間だけの記録になります。
